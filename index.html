How this site works

Built on a shared spreadsheet

Data

Google Sheets

Every list on this site — townies, lots, collections, careers — reads live from a published Google Sheet. Add a row, the site updates.

Media

Cloudinary

Screenshots and portraits are hosted on Cloudinary and referenced by URL in the sheet — no images committed to the repo.

Hosting

GitHub Pages

The whole site is static HTML/CSS/JS — no build step, no server — so it deploys straight from a GitHub repo.
